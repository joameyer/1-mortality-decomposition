# ASIC Hard-Case Comparison Variable Audit Local Review Export Contract

## Purpose

This document defines the default approved export bundle for local review of:

- `evaluation/asic/hard_cases/primary_medians/logistic_regression/asic_hard_case_comparison_variable_audit/`

The goal is to support local interpretation, presentation work, and bounded methodological review
without mirroring any restricted row-level reconstruction inputs.

## Default Approved Aggregate Export Set

These files are approved for the default local-review bundle under:

- `cluster-results/chapter1_true_results/evaluation/asic/hard_cases/primary_medians/logistic_regression/asic_hard_case_comparison_variable_audit/`

### 1. `asic_hard_case_comparison_variable_audit_table.csv`

Purpose:

- compact machine-readable table describing the readiness status of each variable family

### 2. `asic_hard_case_comparison_variable_audit_memo.md`

Purpose:

- narrative audit memo describing join logic, completeness, caveats, and the bounded readiness judgement

### 3. `export_manifest.json`

Purpose:

- staging-time manifest of what was copied into the local-review bundle

Expected contents:

- source directory
- staged directory
- copied relative paths
- excluded relative paths
- timestamp

This file is generated by the staging step and is not copied from the producer package.

## Not Approved In The Default Local Review Bundle

No row-level reconstruction tables, intermediate joins, or additional diagnostics are approved by default.

The cluster-side producer may continue to use restricted inputs in order to build the audit, but the
local mirror should contain only the compact aggregate review artifacts listed above.

## Local Consumer Rule

Default local review of the variable-audit package should rely only on the approved files above.

If a richer diagnostic bundle is needed later, it should be introduced as an explicit contract revision
rather than by manual copying from the cluster working tree.
