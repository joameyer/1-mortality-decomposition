# ASIC Hard-Case Comparison Local Review Export Contract

## Purpose

This document defines the default approved export bundle for local review of:

- `evaluation/asic/hard_cases/primary_medians/logistic_regression/asic_hard_case_comparison/`

The goal is to support local interpretation, reporting, and figure reuse without mirroring
the restricted row-level stay comparison dataset.

## Default Approved Aggregate Export Set

These files are approved for the default local-review bundle under:

- `cluster-results/chapter1_true_results/evaluation/asic/hard_cases/primary_medians/logistic_regression/asic_hard_case_comparison/`

### 1. `comparison_table.csv`

Purpose:

- main local review table for the 24h hard-case vs other-fatal comparison

Expected columns:

- `variable`
- `variable_label`
- `low_predicted_fatal_stays`
- `other_fatal_stays`
- `effect_size_type`
- `effect_size_basis`
- `standardized_difference`
- `absolute_standardized_difference`

### 2. `effect_size_plot_data.csv`

Purpose:

- local-safe plotting helper for the compact effect-size figure

Expected columns:

- `variable`
- `variable_label`
- `figure_label`
- `effect_size_type`
- `effect_size_basis`
- `standardized_difference`
- `absolute_standardized_difference`

### 3. `effect_size_figure.png`

Purpose:

- pre-rendered compact figure for reports, slides, and notebook review

### 4. `summary.md`

Purpose:

- narrative interpretation of the main comparison package for local review

### 5. `early_vs_late_death_split/early_vs_late_fatal_timing_summary.csv`

Purpose:

- local-safe appendix table for the early-vs-late ICU death timing split

Expected columns:

- `early_icu_death`
- `late_icu_death`
- `comparison_statistic`
- `comparison_value`
- `comparison_basis`

### 6. `early_vs_late_death_split/early_vs_late_low_pred_share.png`

Purpose:

- pre-rendered appendix figure for the timing split

### 7. `early_vs_late_death_split/early_vs_late_interpretation_note.md`

Purpose:

- local-safe appendix note for the timing split

### 8. `export_manifest.json`

Purpose:

- staging-time manifest of what was copied into the local-review bundle

Expected contents:

- source directory
- staged directory
- copied relative paths
- excluded relative paths
- timestamp

This file is generated by the staging step and is not copied from the producer package.

## Not Approved In The Default Local Review Bundle

These artifacts are excluded by default:

### `stay_level_comparison_dataset.csv`

Reason:

- row-level stay dataset
- contains restricted/static-derived fields at per-stay granularity

### `run_manifest.json`

Reason:

- producer-side internal provenance artifact
- references restricted-input build context
- not needed for local scientific review once the export bundle is fixed

### `standardized_difference_details.csv`

Reason:

- more granular diagnostic table than the default local-review workflow requires
- the default local-safe notebook/report path should use the compact comparison table and figure helpers instead
- can be reconsidered later only as an explicit extension to the export contract

## Local Consumer Rule

Default local review of the hard-case comparison package should rely only on the approved files above.

If deeper diagnostics are needed later, they should be added through an explicit revision of this
contract rather than by ad hoc copying from the cluster working tree.
