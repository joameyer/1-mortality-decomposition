# ASIC Hard-Case Comparison Variable Audit Local Review Decision

## Decision

`asic_hard_case_comparison_variable_audit` should get its **own local-safe aggregate export contract**.

It should **not** remain a cluster-side-only review artifact.

## Why

The producer script is cluster-side because it reconstructs the audit from restricted inputs:

- blocked dynamic data
- static harmonized data
- model-ready rows
- cohort timing metadata

But the emitted outputs are already aggregate review artifacts:

- `asic_hard_case_comparison_variable_audit_table.csv`
- `asic_hard_case_comparison_variable_audit_memo.md`

Those outputs summarize:

- variable-family readiness
- completeness counts
- join logic at a descriptive level
- readiness notes and caveats

They do **not** export a row-level patient table.

## Evidence From Current Repo Usage

Downstream local-review/reporting code already treats the memo as a local review input:

- [reports/ch1_methods_results_presentation.md](/Users/joanameyer/repository/1-mortality-decomposition/reports/ch1_methods_results_presentation.md:314)
- [reports/ch1_presentation_deck_overview.md](/Users/joanameyer/repository/1-mortality-decomposition/reports/ch1_presentation_deck_overview.md:302)
- [build_ch1_methods_results_presentation.py](/Users/joanameyer/repository/1-mortality-decomposition/scripts/build_ch1_methods_results_presentation.py:1180)

The producer itself writes only:

- [asic_hard_case_comparison_variable_audit_table.csv](/Users/joanameyer/repository/1-mortality-decomposition/scripts/ch1_asic_hard_case_comparison_variable_audit.py:43)
- [asic_hard_case_comparison_variable_audit_memo.md](/Users/joanameyer/repository/1-mortality-decomposition/scripts/ch1_asic_hard_case_comparison_variable_audit.py:44)

## Boundary Interpretation

So the right split is:

- cluster-side producer: keep
- local-safe exported outputs: yes

This is the same pattern as other mixed analyses:

- restricted joins happen on the cluster
- compact aggregate interpretation artifacts are mirrored locally

## Default Recommendation

The default local-review bundle for this audit should include:

- `asic_hard_case_comparison_variable_audit_table.csv`
- `asic_hard_case_comparison_variable_audit_memo.md`
- an export manifest generated by the staging step

## Not Needed In The Default Bundle

No additional diagnostic or row-level audit artifacts should be exported by default.

If a richer audit bundle is needed later, it should be introduced as an explicit contract revision.
