## 1. Executive Summary

- This repository is the standalone Chapter 1 preprocessing and baseline-analysis layer for a mortality risk-structure study in ventilated ICU patients.
- The Chapter 1 question is not "can we build the best mortality model?" but "do some fatal outcomes remain weakly captured by standard short-horizon risk models under the recorded ICU feature set and time resolution?"
- The frozen development dataset is ASIC. MIMIC-IV remains the frozen external-validation target, but no MIMIC-IV result artifacts are present in this repository yet.
- The true ASIC cluster run now provides a full-scale internal evidence base: 15,969 input stays, 6,446 retained stays, and 1,548,220 valid prediction instances across the five frozen horizons.
- The frozen stay-level split now behaves as intended on true data: 4,511 train stays, 968 validation stays, and 967 test stays, each with nearly identical stay-level mortality prevalence around 26.8%.
- At the prediction-instance level, the 24h primary test split is fully evaluable: 33,676 test rows with 752 positives.
- At 24h, XGBoost is stronger on discrimination than logistic regression on the test split, but logistic regression is much cleaner on calibration and Brier score. Because Chapter 1 is calibration-first, logistic remains the better narrative anchor for the main deck.
- Under the frozen logistic hard-case rule, 346 of 1,682 fatal 24h stays are low-predicted, or about 20.6% of fatal stays.
- That low-predicted fatal burden is remarkably stable across horizons, and the horizon package labels the pattern `persist`.
- Decomposition is still optional and secondary. The current Chapter 1 backbone is already defensible as a risk-structure and hard-case chapter without making decomposition the organizing logic.

## 3. Frozen Definitions And Key Design Choices

### Frozen Chapter 1 framing

- Chapter 1 is about heterogeneous predictability under the observed feature set, not biological death subtypes.
- Baseline risk models are operational instruments for identifying low-predicted fatal cases.
- Calibration is a gating issue before hard-case interpretation.
- Decomposition is secondary and should stay easy to drop.

### Frozen outcome and time choices

- Primary horizon: 24h.
- Main horizon contrast: 48h.
- Sensitivity horizons: 8h, 16h, 72h.
- Unit of analysis: patient-time prediction instances at completed 8-hour blocks.

### Implemented cohort and instance rules

- Adult age `>=18` is trusted upstream rather than rederived here.
- Mechanical ventilation `>=24h` is enforced via `mech_vent_ge_24h_qc`.
- First-stay handling is proxied by `readmission == 0`.
- Valid instances require block eligibility plus at least 3 of 4 core physiologic groups within the block.
- ASIC still lacks patient identifiers, so operational splitting remains stay-level rather than true patient-level.

### Implemented label rule

- Labels are proxy within-horizon in-ICU mortality labels, not true event-timed labels.
- Positive at horizon `H`: `icu_mortality == 1` and `icu_end_time_proxy_hours` lies in `(t, t+H]`.
- Negative at horizon `H`: `icu_mortality == 0` and `icu_end_time_proxy_hours >= t+H`.
- All other rows remain unlabeled rather than being coerced negative.

### Feature and preprocessing boundary

- Primary feature set contains 31 base features.
- Extended adds 15 more variables.
- No high-complexity bespoke feature engineering is introduced.
- Bounded LOCF is applied only to prespecified feature families.
- Ventilator-variable LOCF is restricted to ventilation-supported windows.
- Missingness indicators are appended.
- Final imputation is deferred to downstream model training only.

### Split design

- Target split: `70/15/15`.
- Split unit: `stay_id_global`.
- Splitting is done within retained hospitals and pooled.
- Split seed is frozen as `20260327`.
- Important phrasing: the frozen scientific intent is patient-level splitting, but the actual implementation is stay-level because ASIC lacks patient identifiers.

## 4. Current Chapter 1 Essential Findings

### Findings that are methodological and safe to present now

- The Chapter 1 preprocessing pipeline is operational end-to-end on true ASIC results: cohort restriction, valid-instance generation, proxy labels, model-ready export, observation-process features, and split assignment all exist and pass verification checks.
- Observation-process instrumentation is substantial on true data:
  - 248,772 unique usable 8-hour blocks before horizon duplication
  - 69.4% of usable blocks observe all 4 core physiologic groups in-block
  - the remaining 30.6% still observe 3 of 4 core groups, matching the frozen inclusion rule
- The horizon-specific positive burden increases as expected:
  - 8h: 1,639 / 236,204 labelable instances (0.69%)
  - 16h: 3,307 / 233,965 (1.41%)
  - 24h: 4,986 / 231,596 (2.15%)
  - 48h: 9,800 / 224,195 (4.37%)
  - 72h: 14,207 / 216,573 (6.56%)
- The stay-level split is well balanced on true data:
  - train: 4,511 stays, mortality prevalence 26.76%
  - validation: 968 stays, mortality prevalence 26.76%
  - test: 967 stays, mortality prevalence 26.78%
- The hard-case workflow is frozen and reproducible: `asic_logistic_last_eligible_nonfatal_q75_v1`.
- ICD-10-based coarse disease grouping is feasible at scale, but the retained cohort is dominated by surgical/postoperative/trauma-related and respiratory/pulmonary categories:
  - surgical/postoperative/trauma-related: 59.3%
  - respiratory/pulmonary: 32.8%
  - cardiovascular: 5.2%
  - infection/sepsis non-pulmonary: 1.7%
  - neurologic: 0.6%

### Core empirical findings that belong in the main deck

- The frozen test split is binary-evaluable for all horizons and both baseline models. This removes the main synthetic/local-run limitation from the previous version of the overview.
- At 24h on the test split:
  - Logistic regression: AUROC 0.819, AUPRC 0.268, calibration slope 0.974, Brier 0.0186
  - XGBoost: AUROC 0.848, AUPRC 0.318, calibration slope 1.162, Brier 0.1351
- Interpretation for the deck:
  - If the emphasis is discrimination alone, XGBoost is stronger.
  - If calibration is central, logistic regression is the cleaner baseline and should remain the main narrative anchor.
- The frozen logistic hard-case definition identifies a substantial minority of fatal 24h stays as low-predicted:
  - 346 hard cases out of 1,682 fatal stays at 24h
  - hard-case share among 24h fatal stays: 20.57%
- The hard-case share is stable across horizons:
  - 8h: 21.42%
  - 16h: 20.48%
  - 24h: 20.57%
  - 48h: 20.74%
  - 72h: 21.36%
- The 24h hard-case comparison is now large enough to be meaningfully descriptive:
  - low-predicted fatal stays: 346
  - other fatal stays: 1,336
- In that true 24h comparison, low-predicted fatal stays are characterized by:
  - slightly earlier last eligible prediction time before ICU end
  - higher MAP
  - moderately higher PF ratio
  - lower PEEP
  - only modest demographic/site/disease-group imbalances overall
- The strongest categorical enrichments in the true 24h comparison are modest rather than dramatic:
  - `asic_UK04`: 11% of hard cases vs 5% of other fatal stays
  - neurologic group: 2% vs 0%
- Cross-model agreement at 24h is moderate, not negligible:
  - logistic hard cases: 346
  - recalibrated XGBoost hard cases: 227
  - overlap: 188
  - Jaccard: 0.488
- Horizon dependence now looks much stronger and cleaner than in the synthetic local run:
  - mean pairwise Jaccard: 0.828
  - 24h vs 48h Jaccard: 0.885
  - final horizon package label: `persist`
- The 8h vs 16h temporal preview shows some movement, but not collapse:
  - logistic 24h AUROC: 0.819 to 0.816
  - logistic 24h AUPRC: 0.268 to 0.235
  - XGBoost 24h AUROC: 0.848 to 0.846
  - XGBoost 24h AUPRC: 0.318 to 0.291

### Findings that still need careful phrasing

- Hard-case structure is real enough to describe, but it is not the same as proving a biological subtype.
- Cross-model agreement is only moderate, so hard cases should not be framed as model-invariant.
- The temporal preview is informative, but still too narrow to justify any Chapter 1 refreeze by itself.
- Some autogenerated markdown memos in the cluster bundle retain stale "synthetic" wording; the numeric cluster summaries should be treated as authoritative instead.

## 9. Risks Of Misframing Or Overclaiming

| risk | why it is risky | safer phrasing |
| --- | --- | --- |
| Presenting Chapter 1 as death-subtype discovery | Frozen docs explicitly reject biological subtype claims | "heterogeneous predictability under the observed feature set" |
| Saying low-predicted deaths are inherently unpredictable | Chapter 1 cannot distinguish unobserved from unobservable | "poorly captured in the recorded data at this resolution" |
| Treating proxy labels as true death timing | Labels use `icu_end_time_proxy_hours`, not true death timestamps | "proxy within-horizon in-ICU mortality labels" |
| Saying the split is patient-level | ASIC lacks patient identifiers | "operationally stay-level after first-stay proxy filtering" |
| Treating AUROC/AUPRC as the whole model story | Chapter 1 is calibration-first; discrimination and calibration point in different directions here | "XGBoost discriminates better, logistic is cleaner for calibration-oriented interpretation" |
| Presenting hard-case shares as natural classes | Hard cases are operational and model-dependent | "low-predicted fatal stays under the frozen Chapter 1 rule" |
| Claiming model-invariant hard cases | 24h logistic vs recalibrated-XGBoost Jaccard is 0.488, not near-complete agreement | "moderate cross-model overlap" |
| Overstating horizon stability as proof of a subtype | Persistence across horizons is descriptive, not ontological proof | "the low-predicted fatal burden persists descriptively across horizons" |
| Framing decomposition as the chapter backbone | The risk-structure and hard-case story already stands without it | "optional secondary summary layer" |
| Using SOFA as if it were available | SOFA remains not feasible in the saved audit | "direct organ-support/dysfunction proxies instead of SOFA" |
| Implying external validation is already done | MIMIC-IV artifacts are not yet present | "external validation remains required work" |

## Bottom-Line Recommendation For The Deck

- Build the main deck around frozen scientific framing, the true ASIC cohort and split, calibration-first baseline evaluation, the full-data 24h hard-case comparison, and the now much stronger horizon-persistence story.
- Use logistic regression as the main risk-structure anchor because Chapter 1 is calibration-first, while still showing that XGBoost discriminates better.
